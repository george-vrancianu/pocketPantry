Recipe Tags filter — handoff prototype

For #706 / #711, variant C picked. A Tags button beside search replaces the Cuisine and Method chip rows and their Clear chip. It opens a sheet with the shared Tag field (MUI Autocomplete: multiple, limitTags, groupBy) and its list always open. Picked Tags show as removable chips under search. The list and the rows are live.

What's live

  • AND: every picked Tag must be on the Recipe. Tags and text search combine (try “soup” + Freezer-friendly).
  • Options are only Tags used on at least one of the family's Recipes, grouped under their Tag Group, Your Tags first (Family Tags in butter, Catalog Tags in green). “Party” and “Indian” exist but are on no Recipe, so they never show.
  • Type in the field to narrow the options; case and accents are ignored.
  • Rows show up to 2 Tags + “+N” where Cuisine · Method used to be, then the Level. Tags you filtered by come first and are outlined.
  • While filtering, the groups fold into one Matches list that includes Variants, each matched on its own Tags.
  • Tap Tags: picks apply live behind the sheet, the primary button reads “Show n Recipes”, Clear empties the selection, × / scrim / Escape close it. Tap a chip under search to remove that Tag.
  • Screen readers hear the chips, “and N more Tags” for the overflow, and a polite status line: “Dinner, Vegetarian selected. 2 Recipes match.”

Proposed beyond the spec

  • Each option shows how many Recipes you'd get if you added it; options that would give 0 are dimmed and can't be picked, so AND never leads to an empty list from the dropdown.
  • No-match state offers “Without X · n” buttons to drop one Tag (or the search word).
  • The removable chips under search (one scrolling line, only while Tags are picked) and the count badge on the Tags button.

MUI notes

  • This page loads MUI 5 from a CDN (the last version with a browser bundle). The repo is on MUI 9 inside @pocket-pantry/ui; there renderTags is renderValue, and PopperComponent / componentsProps are slots.popper / slotProps.
  • Props used: multiple, groupBy, limitTags + getLimitTagsText, getOptionDisabled, disableCloseOnSelect, openOnFocus, autoHighlight, forcePopupIcon={false}, custom renderGroup / renderOption, open forced on and a PopperComponent that renders the list in place inside the sheet. The filter has no create option; the editor version (#709/#710) adds Create “…”.
  • Inside the sheet the field wraps its chips and sticks to the top while the list scrolls under it.
