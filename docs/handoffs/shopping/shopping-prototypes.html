Shopping List redesign

Variant C is the approved design. A and B are kept for context. The add sheet, the amount field and the staples inside search are shared by all three. Everything in the phone works: add items, apply or save a template, tick rows, finish.

Shared in all variants

  • Add opens a sheet with search focused. It stays open so you can add several things; Done shows how many you added.
  • Staples live inside search. With an empty search you see missing staples and recently used up as one-tap chips (× dismisses). "Manage" goes to the Staples screen, so the header link is gone.
  • Search results get a category tile, the matched letters highlighted, category · aisle under the name and an "On list" tag.
  • One amount field. Number and unit sit in one input; the unit is a chip inside it. Typing "2kg" or "500 g" sets both.
  • No catalog match: last row adds it as free text.
  • Finish shopping moves into the progress card once something is ticked.
  • Save as template stays on this screen: name it, save, toast with "Edit" instead of jumping to the editor.
