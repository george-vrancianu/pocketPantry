Settings › Family catalog as list rows

Try it

  • Swipe a row left. A short swipe springs back; with the trash tab fully in view the row asks inline (the second line says what uses it); past two thirds it deletes at once, with Undo for 5 s.
  • Hold a row for half a second, or tap it, to open the edit sheet. Keyboard: focus a row, Enter edits, Delete asks.
  • In the sheet: rename, change the category, tag allergens, add or remove other names, or delete. Try renaming to “Tomatoes” for the taken-name error.
  • Other names (Family Synonyms) are rows too: swipe removes the name; hold shows what it means.

    Details

    • Section label “Family catalog” with the scope caption Whole family. The unchecked count becomes an amber line above the lists; it disappears when every ingredient is checked.
    • First-use hint: the first row peeks and a pill reads “Swipe left to delete · hold to edit” (useRowHint('familyCatalog')).
    • Saving sends PATCH (name, leaf) and PUT allergens only for what changed. Toast “Updated {name}”. No API change: unit is shown, not edited, because the PATCH has no defaultUnit.
    • Deleting an ingredient still turns what used it into Unmatched items under its name; the toast reads “Deleted {name}” and Undo cancels the deferred delete.
